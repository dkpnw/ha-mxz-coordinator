# Security policy

## Supported versions

Only the latest release of MXZ Coordinator gets security fixes. Please update to it before you report.

## Reporting a vulnerability

Please report it privately. Don't open a public issue.

1. Go to the repository's [Security tab](https://github.com/dkpnw/ha-mxz-coordinator/security).
2. Choose **Report a vulnerability**.
3. Describe the problem, how to reproduce it, and the MXZ and Home Assistant versions.

Remove tokens, passwords, addresses, and other private details from anything you attach. You'll get a reply in the advisory, and a fix will ship in a new release with credit if you want it.

    About this simulation

    • A running head moves its room 1 °F a minute; other rooms drift toward 76 °F.
    • The stock row follows Mitsubishi's manual for heads on one outdoor unit: "the unit selected last goes into standby mode." It is not stock AUTO. What stock AUTO does.
    • The MXZ row runs the integration's own code at its default settings. Neither row measures real equipment, energy, comfort or noise.
    What the MXZ row leaves out
    • Door and window pauses, Dry, Comfort priority, eco, cloud heads, the shared-mode select and other features with no control here.
    • Slow or unavailable heads, and writes to several heads that interleave. A command a newer plan replaces before it is sent is not modeled.
    • After MXZ takes a change made at a head mid-plan, the next plan here waits for the 10-second cooldown, so it can run up to 10 seconds later than in Home Assistant.
    • Home Assistant finishes taking a change made at a head inside the next plan. No MXZ function says so, so this page follows that order by a rule of its own.
